Objective: To display digits 0–9 on a seven-segment display by controlling individual segments with Arduino.

Components Used: Arduino UNO, Seven-Segment Display, 220 Ω Resistors (x7), Breadboard, Jumper Wires

Output: Display cycles through digits 0–9, changing every 1 second.

Learning Outcome:

Understood how segments (a–g) combine to form digits.
Learned to represent digit patterns using a 2D array.
Reinforced nested for loops iterating over digits and segments.
Understood wiring/current-limiting requirements per segment.

Challenges Faced:

Wrong HIGH/LOW patterns displayed incorrect digits.
Mixed up common cathode vs. common anode wiring.
Missing resistors caused uneven brightness.

Real-World Applications: Digital clocks/counters, scoreboards, numeric readouts.

Connection to PoC: Displays the live count of available parking slots at the entrance, updating as vehicles enter/exit.
